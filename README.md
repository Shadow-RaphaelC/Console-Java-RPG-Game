# Console Java RPG

Wave-based survival RPG played in the console, made in Java (school project, fall 2025). The game is in French.

The assignment asked for a basic hero-vs-monsters fight using an interface and inheritance.
I extended it with 5 zones, monster waves, passive and hostile monsters, a weapon and armor
shop, coins, and a final boss.

## Run

Requires JDK 17+.

```bash
javac -d out src/com/example/libsurvivegame/*.java
java -cp out com.example.libsurvivegame.Main
```
